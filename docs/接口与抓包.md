# 接口与抓包说明

本文档说明美团助手使用的全部接口、token 的获取方式,以及美团调整接口后如何更新配置。

## 一、接口清单

基础域名:`https://i.waimai.meituan.com`,全部为 `POST` + `application/x-www-form-urlencoded`。

请求头:

| Header | 值 |
| --- | --- |
| User-Agent | `MeituanGroup/11.9.208` |
| x-requested-with | `XMLHttpRequest` |
| Content-Type | `application/x-www-form-urlencoded` |

通用 body 参数:`token`(账号凭证)、`parActivityId=Gh1tkq-wvFU2xEP_ZPzHPQ`(活动 ID)、`wm_latitude` / `wm_longitude`(定位)、`wm_ctype=mtandroid`。

> ⚠️ **坐标必须是整型微度(去掉小数点)**:成都 = `wm_latitude=30657401&wm_longitude=104065827`。
> 传小数度(30.657401)会直接被服务端拒绝,返回"参数非法"。这是最容易踩的坑。
> `wm_ctype` 仅 corePage / exchange 需要携带,其余接口不要传(对齐开源脚本 meituan-shenquan)。

| 步骤 | 路径 | 关键参数 | 作用 |
| --- | --- | --- | --- |
| ① 签到领红豆 | `/cfeplay/playcenter/batchgrabred/drawPoints/v2` | token | 每日签到领红豆(7 次/日),同时校验 token |
| ② 签到领必中符 | `/cfeplay/playcenter/batchgrabred/doAction` | `action=SiginInGetProp` | 连续签到领必中符道具 |
| ③ 每日任务红豆 | `/cfeplay/playcenter/batchgrabred/sendTaskRedBean` | `portraitId=498` | 浏览任务领红豆(约 30 豆) |
| ④ 查询红包池 | `/cfeplay/playcenter/batchgrabred/corepage` | 定位参数 | 查询各城市红包池库存与当前批次 batchId |
| ⑤ 抢神券 | `/cfeplay/playcenter/batchgrabred/drawlottery` | `batchId`、`propType=1`、`propId` | 抽奖抢券,返回面值(单位:分) |
| ⑤a 我的道具 | `/cfeplay/playcenter/batchgrabred/myProps` | 定位参数 | 查询必中符道具库(响应 `data` 直接是道具数组) |
| ⑥ 发放到账 | `/cfeplay/playcenter/batchgrabred/acceptRed` | batchId | 把抽中的神券发放到账户 |
| ⑥ 小额转红豆 | `/cfeplay/playcenter/batchgrabred/redToBean` | batchId | 低于阈值的小额券转红豆 |
| ⑦ 我的红包 | `/cfeplay/playcenter/batchgrabred/myreward` | `parActivityId` + token | 查询红包库(列表在 `data.myawardInfos`) |
| ⑧ 兑换必中符 | `/cfeplay/playcenter/batchgrabred/exchange` | `exchangeRuleId`、`propId=5`、`exchangeCoinNumber` | 红豆兑换必中符(需接口返回 exchangeRuleId) |

抢券时段:每天 **11:00 / 17:00 / 21:00**(北京时间),其他时段 ④ 拿不到 batchId,App 会提示"当前不在抢券时段"。

## 二、token 是什么

token 是美团网页版的登录凭证(形式如 `AgAAAA...` 的一长串字符),放在请求 body 的 `token` 字段中。

> 青龙面板脚本里的环境变量 `meituanCookie` 就是这个值,两边通用。

### 获取方式(按推荐程度排序)

**方式 1:App 内置网页登录(推荐,免抓包)**

「账号」页 → ➕ → 网页登录 → 在打开的美团页面中用**美团 App 扫码**或**手机号验证码**登录 → 登录成功后 App 自动从 Cookie 提取 token 并保存。若未自动识别,点登录页内的「手动获取」。

**方式 2:Safari 登录网页版**

1. iPhone Safari 访问 `https://i.meituan.com/` 并登录
2. 登录后地址栏输入 `javascript:alert(document.cookie)`(或借助"获取 Cookie"类快捷指令)
3. 复制弹窗中 `token=xxxx` 的 `xxxx` 部分

**方式 3:抓包(Stream / Thor / Charles)**

1. 美团 App 内打开天天神券活动页
2. 抓包筛选 `i.waimai.meituan.com`,找带 `token=` 的请求
3. 复制 body 中 `token=` 后面的值(注意别带分号)

> 建议用账号密码登录获取,验证码快捷登录的 token 有效期很短。

## 三、接口变更如何更新

美团调整接口时,只需要替换 `endpoints.json`,不用改代码、不用重新编译。三种途径:

### 1. 随 App 打包(开发时)

修改 `MeiTuanTool/Resources/endpoints.json` 中的 `paths`,重新编译。

### 2. 免编译覆盖(推荐)

把改好的 `endpoints.json` 通过「文件」App 放入本 App 的文件夹(iOS 文件 App → 我的 iPhone → 美团助手),下次启动自动生效。加载优先级:

```
Documents/endpoints.json(用户覆盖) > App 内置 endpoints.json > 代码内置默认
```

在「设置 → 接口配置」可查看当前生效的域名/接口数,或一键恢复默认。

### 3. 自定义附加任务(extraTasks)

`endpoints.json` 里的 `extraTasks` 可以追加任意接口,主流程跑完后逐个执行:

```json
"extraTasks": [
  {
    "id": "my-task",
    "name": "我的自定义任务",
    "path": "/cfeplay/playcenter/batchgrabred/myRedBeanRecords",
    "method": "POST",
    "bodyExtra": {
      "userPortraitId": "498",
      "pageNum": "1"
    }
  }
]
```

`token` 和 `parActivityId` 会自动附加,无需写在 `bodyExtra` 里。「设置 → 执行策略 → 执行自定义任务」可开关。

## 四、返回解析说明

美团不同接口的成功码不统一(`code` / `status`),App 做了兼容解析。常见的失效特征:`code=401`、msg 含"登录/失效/过期"——出现这些会标记该账号 token 失效并跳过后续步骤。

关键字段(容错递归查找):

| 字段 | 含义 |
| --- | --- |
| `batchId` | 当前抢券批次,拿不到即不在时段 |
| `showPriceNumber` | 抽中面值,单位分(<500 即 <5 元) |
| `signDays` | 本周连续签到天数 |
| `sendBeanCount` | 本次获得红豆数 |
| `props[].propId` / `props[].status` | 道具 ID / 是否可用(1 可用) |

## 五、黑金会员签到 / 任务(成长值)

美团会员(2025 年上线的成长值体系,黑金是其中等级)的每日签到、任务中心接口**未公开**,也没有开源实现。App 通过「会员中心抓包学习」获得真实接口:

### 首次配置(一次约 1 分钟)

1. 「设置 → 黑金会员任务 → 会员中心抓包学习」打开内置浏览器
2. 在美团 App 里打开「我的 → 会员中心」,点分享 → 复制链接,粘贴到页面顶部输入框打开(默认地址打不开时用分享链接)
3. 在页面里**正常点一次签到**(或做一次任务)
4. 点底部「已捕获 N 个请求 → 查看并添加任务」,找到路径含 `sign` / `task` / `growth` 的请求,点它 → 保存
5. 保存后出现在「设置 → 黑金会员任务」列表中,可删除重配

### 执行

- 首页「会员任务」按钮单独执行,或包含在「一键全流程」里(设置页可开关)
- 快捷指令:`meituantool://run?tasks=member`
- 任务间自动间隔 1.2 秒;执行时自动附加当前账号 token,`token`/`sign`/`timestamp` 等易变字段不会写入配置

### 接口结构

会员任务走独立域名 `memberBaseURL`(默认 `https://member.meituan.com`,可在 endpoints.json 改):

```json
"memberTasks": [
  {
    "id": "UUID",
    "name": "会员签到领成长值",
    "path": "/api/xxx(抓包获得)",
    "bodyExtra": { "cityId": "1" },
    "enabled": true
  }
]
```

执行结果会自动解析 `growthValue` / `growth` / `addGrowthValue` 等成长值字段并显示「成长值 +N」。

> 若某天全部会员任务都报错,大概率是美团调整了接口或 token 未覆盖会员体系:重新进「会员中心」页面确认能打开,再点一次签到让 App 重新学习即可。

## 六、风控提示

- 多账号执行时间隔约 1.5 秒,步骤间亦有间隔,请不要再叠加并发
- 建议每天执行 3~5 次以内(对应三个抢券时段)
- 会员任务建议每天 1 次,与真人节奏错开
- token 失效频繁时,检查是否使用了验证码快捷登录的短期 token
