# 快捷指令自动化配置

> 📱 **手机看图解**:同目录下有 [快捷指令制作图解.html](快捷指令制作图解.html),带全部 6 个自动化的精确配置和一键复制按钮,建议在 iPhone 上打开对照着建。

iOS 系统限制:App 无法常驻后台,也无法被第三方 App 精确定时唤起。要实现"每天 11:00 / 17:00 / 21:00 自动抢券",标准做法是**系统快捷指令的个人自动化 + URL Scheme**。

## 一、URL Scheme 一览

App 注册了 `meituantool`  scheme,支持以下调用:

| URL | 行为 |
| --- | --- |
| `meituantool://run` | 签到 + 领券全流程(默认) |
| `meituantool://run?tasks=sign` | 仅签到(领红豆/必中符/任务豆) |
| `meituantool://run?tasks=coupon` | 仅抢券(红包池 + 抽奖 + 发放) |
| `meituantool://run?notify=0` | 完成后不弹本地通知 |

执行完成后会自动推送本地通知,汇总各账号结果;App 被唤起后会在后台争取约 30 秒把任务跑完,**期间可以锁屏**。

## 二、创建定时个人自动化

以"每天 11:00 抢券"为例:

1. 打开系统「快捷指令」App → 底部「自动化」→ 右上角 ➕ →「创建个人自动化」
2. 触发条件选「特定时间」,设为 **10:58**(提前 2 分钟,留出 App 启动时间;红包池 11:00 才开放,早到会提示不在时段,到点后再次触发即可)
3. 添加动作「打开 URL」,URL 填 `meituantool://run?tasks=coupon`
4. 关闭「运行前询问」(重要!否则每次都要手动确认)
5. 完成保存

重复以上步骤,再创建 17:00、21:00 两个自动化(时间可分别设为 16:58、20:58)。

> 想同时签到,把 URL 改成 `meituantool://run`(全流程)。

### 进阶:整点轮询(提高命中率)

如果希望 11:00 整反复尝试(红包池一开放就抢),可以创建多个自动化:

| 自动化时间 | URL |
| --- | --- |
| 10:58 | `meituantool://run?tasks=coupon` |
| 11:00 | `meituantool://run?tasks=coupon&notify=0` |
| 11:01 | `meituantool://run?tasks=coupon&notify=0` |

最后一次触发保留通知,中间的用 `notify=0` 静默执行。

## 三、后台刷新(App 内开关)

「设置 → 定时自动化 → 允许后台刷新」开启后,App 会向系统登记 `BGAppRefreshTask`,系统会在数小时内的某个时机唤起 App 执行一次全流程。

注意:

- **时机完全由系统决定**(通常几小时一次,取决于你的使用频率),不能精确到分钟
- 适合"兜底签到",不适合"准点抢券"
- 精确定时永远用上面的快捷指令方案

## 四、常见问题

**Q: 自动化到点没执行?**
A: 检查自动化里「运行前询问」是否关闭;iOS 低电量模式会延迟自动化;确保通知/后台刷新权限没被关。

**Q: 锁屏能执行吗?**
A: 可以。URL Scheme 唤起后 App 有约 30 秒后台执行时间,足够跑完 1~2 个账号。账号很多时建议触发后稍等,或保持 App 在前台。

**Q: 为什么快捷指令打开 App 会闪一下界面?**
A: URL Scheme 唤起会短暂展示 App 界面后转后台,属正常现象。

**Q: 想手动测试自动化链接?**
A: Safari 地址栏直接输入 `meituantool://run` 即可手动触发一次全流程。
